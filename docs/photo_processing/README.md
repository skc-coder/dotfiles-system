## 3. Important Guidelines & Checklist

### Photo Capture & Upload Guidelines
- **Lighting & Background**: Taken against a light-coloured background with adequate lighting, face directly looking into the camera.
- **Restrictions**: No caps, hats, or dark/tinted glasses. Religious headwear is allowed provided the face is completely visible. No shadows on face.
- **Live Photograph**: On selecting "Capture Photo", webcam/mobile QR code will capture and auto-upload the live photo.

### Scanning & File Preparation
- **Scanner Settings**: Resolution set to minimum **200 DPI**, colour set to **True Colour**.
- **Format**: File format must be `.jpg` or `.jpeg`.
